# Отчёт по лабораторной работе №3: линейные модели

## 1. Данные и подготовка

В работе использовались два набора данных: `Student_Performance.csv` для задачи линейной регрессии и `german.csv` для задачи бинарной классификации.

### Линейная регрессия

В наборе `Student_Performance.csv` целевой переменной является `Performance Index`.

Признак `Extracurricular Activities` содержит категориальные значения `Yes` и `No`, поэтому перед обучением они были преобразованы в числовой вид:

- `Yes` → 1;
- `No` → 0.

Данные были разделены на обучающую и тестовую выборки в соотношении 80/20 с параметром `random_state=42`.

Для обучения собственной линейной регрессии признаки обучающей выборки были стандартизованы:

`X_scaled = (X - mean) / std`

Среднее значение и стандартное отклонение вычислялись только по обучающей выборке.

Модель обучалась методом пакетного градиентного спуска с параметрами:

- learning rate: 0.05;
- количество эпох: 800;
- функция ошибки: MSE.

### Логистическая регрессия

Для бинарной классификации использовался набор данных `german.csv`.

Целевая переменная `Creditability` находится в первом столбце и принимает значения 0 и 1.

Данные были разделены на обучающую и тестовую выборки в соотношении 80/20 с параметрами:

- `random_state=42`;
- `stratify=y`.

Стратификация использовалась для сохранения соотношения классов в обучающей и тестовой выборках.

Перед обучением признаки также были стандартизованы по статистикам обучающей выборки.

Собственная логистическая регрессия обучалась пакетным градиентным спуском с параметрами:

- learning rate: 0.1;
- количество эпох: 1000;
- функция потерь: binary cross-entropy;
- порог классификации: 0.5.

Для преобразования линейного выхода модели в вероятность использовалась сигмоидная функция.

## 2. Гипотезы и эксперименты

Для линейной регрессии предполагалось, что после масштабирования признаков пакетный градиентный спуск сможет стабильно уменьшать MSE.

В начале обучения значение MSE составляло:

`3428.035`

После 800 эпох значение MSE на обучающей выборке уменьшилось до:

`4.169735849525007`

Это показывает, что алгоритм градиентного спуска успешно сошёлся.

Итоговое значение MSE на тестовой выборке:

`4.082628398521853`

Для классификации была реализована собственная логистическая регрессия и проведено сравнение с моделями из scikit-learn:

- Logistic Regression;
- Decision Tree;
- KNN.

Все модели проверялись на одном и том же разбиении данных.

Начальное значение binary cross-entropy собственной логистической регрессии:

`0.6931471805579454`

После обучения значение уменьшилось до:

`0.48213176300118327`

Таким образом, в процессе обучения функция потерь уменьшилась, что свидетельствует о корректной работе градиентного спуска.

## 4. Выводы

Собственная линейная регрессия успешно обучилась методом пакетного градиентного спуска. MSE уменьшилась с 3428.035 до 4.169735849525007 на обучающей выборке. На тестовой выборке MSE составила 4.082628398521853.

Собственная логистическая регрессия также показала стабильное обучение. Binary cross-entropy уменьшилась с 0.6931471805579454 до 0.48213176300118327.

Результаты собственной логистической регрессии практически совпали с результатами готовой Logistic Regression из scikit-learn. Accuracy, Precision, Recall и F1 полностью совпали. ROC-AUC собственной модели составил 0.8080952380952382, а у реализации scikit-learn — 0.8085714285714287.

Decision Tree показал более низкие значения метрик. Его Accuracy составила 0.685, а ROC-AUC — 0.6226190476190476.

KNN показал результат лучше Decision Tree, но хуже логистической регрессии. Accuracy модели составила 0.72, ROC-AUC — 0.7411904761904762, F1 — 0.8108108108108109.

Таким образом, на данном разбиении данных собственная реализация логистической регрессии показала результаты, близкие к реализации scikit-learn, и более высокие значения основных метрик по сравнению с Decision Tree и KNN.

Одной из причин хорошего результата логистической регрессии может быть то, что после стандартизации данных линейная граница решений достаточно хорошо описывает зависимости в рассматриваемом наборе данных.
